VANE'SS BOUTIQUE - CAISSE GRATUITE

INSTALLATION GRATUITE AVEC GITHUB PAGES
1. Créer un compte gratuit sur github.com.
2. Créer un dépôt PUBLIC (par exemple vaness-caisse). Attention : les fichiers du code sont publics, ne jamais y mettre de données clientes ou secrets.
3. Envoyer les fichiers de ce dossier à la racine du dépôt (pas le ZIP).
4. Dans Settings > Pages, choisir Deploy from a branch, main, /(root), puis Save.
5. Attendre la publication et ouvrir l'adresse HTTPS indiquée dans Pages avec Safari sur l'iPhone.
6. Dans Safari, Partager > Sur l'écran d'accueil > Ajouter.
7. Ouvrir l'application avec connexion une fois, puis tester le mode avion et un PDF avant une vraie vente.

IMPORTANT
- Les ventes sont conservées UNIQUEMENT sur l'appareil et dans ce navigateur / cette installation. Pas de synchronisation entre appareils.
- Exporter une sauvegarde JSON après chaque journée et la conserver dans Fichiers/iCloud. Tester la restauration.
- Ne pas effacer les données de Safari sans sauvegarde.
- Le PDF est un reçu simplifié; vérifier les mentions professionnelles et obligations légales selon les ventes.
- GitHub Pages est gratuit sous réserve des conditions de l'offre. Pas de frais récurrents imposés par le code.
- Le code n'encaisse pas les paiements et n'envoie pas automatiquement les PDF.
